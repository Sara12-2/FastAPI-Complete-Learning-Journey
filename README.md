## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Sara12-2/FastAPI-Complete-Learning-Journey.git
```

### 2. Navigate to the Project

```bash
cd FastAPI-Complete-Learning-Journey
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment (Windows CMD)

```cmd
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install "fastapi[standard]"
```

### 6. Run FastAPI Application

```bash
uvicorn main:app --reload
```

### 7. Explore API Documentation

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc
